# quant — Can an LLM Create a Genuinely Novel Trading Edge?

An experiment testing whether an LLM (Claude, with tools) can produce a trading signal that is
**novel** (no findable prior art) and **empirically validated** (survives a pre-registered,
multiple-testing-corrected out-of-sample gauntlet) — or whether it can only recombine its
training data.

**The final deliverable is [`REPORT.md`](REPORT.md).**

## Design in one paragraph

Novelty is made decidable by a frozen tiered scale
([`research/methodology/novelty_scale.md`](research/methodology/novelty_scale.md)) plus a
provenance grade ("could this be regurgitation?"). The experimental rules — data splits, a
locked holdout enforced in code and git history, promotion gates, a trials ledger that makes
every backtest ever run count against the Deflated Sharpe Ratio — were pre-registered before
any analysis ([`research/methodology/protocol.md`](research/methodology/protocol.md)).
Candidates are generated by four mechanisms designed to escape training-data regurgitation,
then attacked: adversarial literature searches try to prove each survivor is already known,
and a statistical red team re-implements each from its spec alone. A negative result is a
valid, publishable outcome.

## Layout

```
REPORT.md                    the final deliverable
research/methodology/        frozen novelty scale + pre-registered protocol
research/prior_art/          literature sweeps + machine-readable factor database
research/debates/            adversarial-review transcripts for every phase
data/                        universe, download manifest (parquet cache gitignored)
src/quantlab/                data pipeline, backtester, statistics, holdout gate, signal DSL
tests/                       no-lookahead test, statistics pinned to paper values
candidates/                  specs, registry (pre-registration hashes), trials ledger, results
```

## Reproduce

```bash
pip install -r requirements.txt
python -m pytest tests/            # no-lookahead + stats pins must be green
python -m quantlab.data download   # populate data/cache/ from Yahoo (browser UA required)
```
