## Minor nitpicks (NOT objections)

1. C18: the feature-map dimensions are listed in the abstract as "strategy type, risk profile, turnover, and return characteristics"; the file says "strategy type, risk, and return characteristics," silently dropping turnover. A subset, not an error.
2. C30 evidence line renders the FunSearch "first discoveries" point as a quotation ("the first discoveries in open problems in mathematical sciences using LLMs") but the blog's actual sentence is "the first time a new discovery has been made for challenging open problems in science or mathematics using LLMs" (the file's version blends the post title with that sentence). The claim body itself calls it an "existence proof" and is accurate; only the evidence-line quotation marks are loose.
3. C2: the paper's own emergence wording is "financial decision-making ability is an emerging capacity of more complex LLMs"; the file's "financial return prediction from text appears to be an emergent capability" is a fair paraphrase flagged with "i.e." — fine.
4. C9: a WebFetch summary of the abs page reported "Submission Date: May 25, 2023," inconsistent with the 2306.* identifier; the file makes no month claim for AlphaGen, so nothing to correct.
5. C20: the SSRN "Dec 2015" date rests on an SSRN search snippet (posted December 9, 2015) since SSRN pages are proxy-blocked; consistent with the arXiv v1 of January 5, 2016.
